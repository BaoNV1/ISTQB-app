1. Fundamentals of Testing

  • Objectives: Find defects, build confidence, reduce risk.
  • 7 Principles (key!): Exhaustive testing impossible, absence-of-defects fallacy, etc.

2. Testing in SDLC

  • Test levels: Unit → Integration → System → Acceptance.
  • Test types: Functional, non-functional, white/black-box.
  • Maintenance & regression testing.
