# ISTQB Chapter 2 Glossary

## Key terms
- SDLC (Software Development Lifecycle): The process used to build and maintain software.
- Test level: A stage in testing such as component, integration, system, or acceptance testing.
- Test type: A category of testing such as functional or non-functional testing.
- Component testing: Testing individual components or modules.
- Integration testing: Testing interactions between components.
- System testing: Testing the whole system as a complete product.
- Acceptance testing: Testing to confirm the system satisfies business needs and acceptance criteria.
- Confirmation testing: Testing to verify a defect has been fixed.
- Regression testing: Testing to ensure previously working functionality still works after changes.
- Maintenance testing: Testing performed after release when changes are made.
- Shift left: Moving testing earlier in the lifecycle.
- DevOps: A collaborative approach linking development and operations.
- Test-first approach: Writing tests before implementation.
