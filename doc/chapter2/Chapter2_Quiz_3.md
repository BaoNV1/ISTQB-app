# ISTQB CTFL v4.0.1 – Chapter 2 Additional Quiz 3
## Test Integration in SDLC Models - Part 3

---

### Question 1
The V-Model is particularly useful because:

A. It is faster than Waterfall  
B. It clearly shows the relationship between development and testing phases  
C. It eliminates the need for documentation  
D. It allows unlimited changes during development  

**Answer:** B  
**Explanation:**  
The V-Model visually represents how each development phase (left side) has a corresponding testing phase (right side), showing test activities for different levels.

---

### Question 2
Which statement about Iterative and Incremental models is TRUE?

A. Testing cannot begin until all features are developed  
B. Requirements must be fully defined before development starts  
C. Testing starts early in each iteration, with a complete system built incrementally  
D. They are identical to Waterfall  

**Answer:** C  
**Explanation:**  
Iterative models repeat cycles of design-implement-test. Incremental models build features piece by piece. Both allow testing to start early.

---

### Question 3
In an Agile/Scrum environment, the test team:

A. Works in isolation from the development team  
B. Is part of the development team and participates in daily standups and sprint planning  
C. Only reports defects at the end of the project  
D. Never participates in requirement discussions  

**Answer:** B  
**Explanation:**  
Agile emphasizes cross-functional teams where testers work closely with developers and product owners throughout the sprint.

---

### Question 4
Exploratory Testing is most suitable when:

A. Requirements are well-defined and stable  
B. Documentation is complete  
C. There is limited time and requirements are not fully defined or change frequently  
D. Only manual testing is forbidden  

**Answer:** C  
**Explanation:**  
Exploratory Testing allows testers to adapt tests dynamically based on discoveries, making it suitable for evolving requirements or time-constrained situations.

---

### Question 5
The relationship between test implementation and test design is:

A. They are the same activity  
B. Test design creates test cases; test implementation automates or prepares execution of these tests  
C. Test implementation happens before test design  
D. Test implementation is only for automated tests  

**Answer:** B  
**Explanation:**  
Test design defines what to test and creates test cases. Test implementation takes those cases and prepares them for execution (automation, data setup, etc.).
