# ISTQB CTFL v4.0.1 – Chapter 5 Practice Quiz 2
## Focus: Planning, Estimation, Pyramid & Quadrants

---

### Question 1
Which statement about entry criteria is TRUE?

A. They are defined only after all tests pass  
B. Typical examples include availability of resources, testware, and an acceptable initial quality level  
C. They are the same as exit criteria  
D. They are never used in Agile  

**Answer:** B  
**Explanation:** Entry criteria include readiness of people, tools, environments, data, test basis, and initial quality (e.g. smoke tests passed).

---

### Question 2
Stakeholders accept going live even though planned coverage is incomplete because time ran out. This situation is best described as:

A. Invalid; testing can never stop  
B. Using time/budget as an exit criterion with accepted residual risk  
C. A product risk only, never a project decision  
D. Proof that exit criteria are unnecessary  

**Answer:** B  
**Explanation:** Running out of time or budget can be a valid exit criterion if stakeholders review and accept residual risk.

---

### Question 3
Definition of Ready is closest to:

A. Exit criteria for release  
B. Entry criteria for starting development and/or testing of a user story  
C. A type of defect severity  
D. A test completion report  

**Answer:** B  
**Explanation:** In Agile, Definition of Ready is entry criteria a story must fulfill before development/testing starts.

---

### Question 4
Experts estimate test effort iteratively, discuss differences, and re-estimate until they agree. Which technique is this?

A. Equivalence partitioning  
B. Wideband Delphi  
C. Branch coverage  
D. State transition testing  

**Answer:** B  
**Explanation:** Wideband Delphi is iterative expert-based estimation until consensus; Planning Poker is a variant.

---

### Question 5
Three-point estimates for a task: optimistic 6, most likely 10, pessimistic 18. Using E = (a + 4m + b) / 6, which value is correct?

A. 8  
B. 10  
C. (6 + 40 + 18) / 6 = 64/6  
D. 18  

**Answer:** C  
**Explanation:** E = (a + 4m + b) / 6 = (6 + 40 + 18) / 6 = 64/6 (about 10.7 person-days).

---

### Question 6
Which prioritization factor is most aligned with risk-based testing?

A. Alphabetical order of test names  
B. Higher likelihood and impact of failure in the area under test  
C. Random selection  
D. Only the length of the test script  

**Answer:** B  
**Explanation:** Risk-based prioritization uses product risk (likelihood and impact).

---

### Question 7
According to the test pyramid, which layer should usually have the largest number of automated tests?

A. End-to-end UI tests  
B. Unit / component tests  
C. Manual UAT only  
D. Exploratory sessions only  

**Answer:** B  
**Explanation:** The base of the pyramid is many fast unit/component tests.

---

### Question 8
API tests that check acceptance criteria and support the team are most associated with:

A. Q1  
B. Q2  
C. Q3  
D. Q4  

**Answer:** B  
**Explanation:** Q2 is business-facing and supports the team (functional tests, examples, story tests, API checks against acceptance criteria).

---

### Question 9
Which statement about testing quadrants is TRUE?

A. Q3 tests are only automated performance tests  
B. Q1 tests are typically technology-facing and support the team  
C. All quadrants forbid automation  
D. Q4 contains only usability testing  

**Answer:** B  
**Explanation:** Q1 = technology-facing, support the team; Q4 includes non-functional tests such as performance/security (usability is Q3).

---

### Question 10
A test plan should demonstrate adherence to:

A. Only the coding standard of one developer  
B. Existing test policy and test strategy (or explain deviations)  
C. Marketing slogans only  
D. No organizational documents  

**Answer:** B  
**Explanation:** The plan shows testing will follow policy and strategy or explains why it will deviate.
