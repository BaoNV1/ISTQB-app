# Chapter 5 Additional Quiz – Managing the Test Activities Part 2

### Question 1
Risk Level is calculated as:
A. Likelihood + Impact  
B. Likelihood × Impact  
C. Impact – Likelihood  
D. Number of defects  

**Answer:** B  

**Explanation:** Risk Level = Likelihood × Impact. This multiplication shows that even a small likelihood with high impact results in significant risk.

### Question 2
Which is a Product Risk?
A. Tester is sick  
B. Test environment delayed  
C. System may crash under high load  
D. Budget is reduced  

**Answer:** C  

**Explanation:** Product risks relate to the quality and behavior of the software itself. System crashes under load is a quality risk.

### Question 3
Entry Criteria define:
A. When testing can finish  
B. When testing can start  
C. Only defect counts  
D. Only test tools  

**Answer:** B  

**Explanation:** Entry criteria must be met before testing can begin (e.g., requirements approved, code ready, environment available).

### Question 4
The Test Pyramid recommends:
A. Many UI tests at the bottom  
B. Many unit tests at the bottom, fewer end-to-end tests at the top  
C. Only manual tests  
D. Equal tests at every level  

**Answer:** B  

**Explanation:** The test pyramid suggests having many quick unit tests at the base, fewer integration tests in the middle, and few expensive end-to-end tests at the top.

### Question 5
A good Defect Report should include:
A. Only the defect title  
B. Steps to reproduce, expected result, actual result, severity  
C. Full source code  
D. Only the tester's name  

**Answer:** B  

**Explanation:** Effective defect reports include: summary, steps to reproduce, expected vs actual results, severity, priority, environment, and attachments.
