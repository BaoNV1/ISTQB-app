# ISTQB CTFL v4.0.1 – Chapter 5 Additional Quiz 3
## Managing the Test Activities - Part 3

---

### Question 1
What is the purpose of Risk-Based Testing?

A. To eliminate all risks in the software  
B. To prioritize testing efforts on areas of highest risk, maximizing defect detection  
C. To avoid testing high-risk areas  
D. To replace all other testing techniques  

**Answer:** B  
**Explanation:**  
Risk-based testing allocates more testing resources to areas with high probability and/or impact of failure, optimizing test efforts.

---

### Question 2
Which of the following is a Project Risk in testing?

A. A critical function in the software may fail  
B. The test environment is not ready on schedule  
C. The system may have performance issues  
D. A security vulnerability exists in the code  

**Answer:** B  
**Explanation:**  
Project risks affect the testing process itself (resources, schedule, tools, environment). Product risks relate to the software quality.

---

### Question 3
Exit criteria should be defined:

A. At the end of testing when results are known  
B. During test planning before testing begins  
C. Only for acceptance testing  
D. Never, they are not important  

**Answer:** B  
**Explanation:**  
Exit criteria should be established during test planning to define the conditions that must be met for testing to be considered complete.

---

### Question 4
What is the main purpose of test progress monitoring?

A. To find defects  
B. To track actual progress against planned metrics and identify deviations early  
C. To execute test cases  
D. To write test documentation  

**Answer:** B  
**Explanation:**  
Monitoring gathers metrics (cases executed, defects found, coverage %, etc.) and compares them to the plan to enable control actions.

---

### Question 5
Which statement about test reporting is TRUE?

A. Test reports should only be created after testing is complete  
B. Test reports should only mention defects  
C. Test reports should be created regularly during testing and provide clear information for stakeholders  
D. Test reports are only for the development team  

**Answer:** C  
**Explanation:**  
Regular test reports throughout the testing process keep stakeholders informed of progress, risks, and quality status, enabling better decision-making.
