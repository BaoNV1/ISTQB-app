# Từ vựng ISTQB Chương 5 (Tiếng Việt)

Bảng này giúp bạn tra cứu nhanh từng thuật ngữ và nghĩa của nó.

| Thuật ngữ | Nghĩa |
|---|---|
| Test plan | Tài liệu mô tả cách tiếp cận, phạm vi, nguồn lực và lịch trình cho kiểm thử. |
| Entry criteria | Các điều kiện phải được thỏa mãn trước khi kiểm thử bắt đầu. |
| Exit criteria | Các điều kiện phải đạt được trước khi kiểm thử được coi là hoàn tất. |
| Estimation | Dự đoán lượng công sức, thời gian và nguồn lực cần cho kiểm thử. |
| Test case prioritization | Quyết định test nào nên được thực thi trước dựa trên mức độ quan trọng hoặc rủi ro. |
| Test pyramid | Một mô hình đề xuất có nhiều unit test nhỏ, nhanh, ít integration test hơn và thậm chí ít UI test hơn. |
| Testing quadrants | Một mô hình phân loại kiểm thử dựa trên mối quan tâm hướng tới doanh nghiệp và hướng tới công nghệ. |
| Risk | Khả năng xảy ra một sự kiện hoặc kết quả tiêu cực. |
| Project risk | Rủi ro liên quan đến dự án, ví dụ chậm tiến độ, thiếu nguồn lực hoặc lập kế hoạch kém. |
| Product risk | Rủi ro liên quan đến chất lượng hoặc hành vi của sản phẩm. |
| Risk analysis | Xem xét rủi ro để hiểu xác suất và tác động của nó. |
| Risk control | Các hành động nhằm giảm hoặc quản lý rủi ro. |
| Risk-based testing | Kiểm thử kỹ hơn ở các khu vực có rủi ro cao hơn. |
| Test monitoring | Theo dõi tiến độ và so sánh kết quả thực tế với kế hoạch. |
| Test control | Hành động để giữ kiểm thử phù hợp với mục tiêu. |
| Test progress report | Báo cáo cho thấy đã kiểm thử những gì, phần còn lại và trạng thái hiện tại. |
| Test completion report | Báo cáo được tạo khi kiểm thử kết thúc, tóm tắt kết quả và rủi ro còn lại. |
| Configuration management | Quá trình kiểm soát thay đổi đối với sản phẩm làm việc và giữ tổ chức các phiên bản. |
| Defect management | Quá trình báo cáo, theo dõi và giải quyết defect. |
| Defect report | Tài liệu mô tả defect một cách rõ ràng và bao gồm các chi tiết liên quan như bước tái hiện, kết quả mong đợi và kết quả thực tế. |

## Mẹo ghi nhớ nhanh

Lập kế hoạch trước, sau đó giám sát, điều khiển và báo cáo.
