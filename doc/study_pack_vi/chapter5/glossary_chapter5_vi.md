# Từ vựng Chương 5 (Tiếng Việt)

| Thuật ngữ | Nghĩa |
|---|---|
| Test plan | Kế hoạch kiểm thử. |
| Entry criteria | Điều kiện bắt đầu kiểm thử. |
| Exit criteria | Điều kiện kết thúc kiểm thử. |
| Estimation | Ước lượng công sức kiểm thử. |
| Test case prioritization | Ưu tiên các test case. |
| Test pyramid | Mô hình cân bằng giữa unit, integration và UI test. |
| Testing quadrants | Mô hình phân loại kiểm thử theo mục đích và mức độ. |
| Risk | Rủi ro. |
| Project risk | Rủi ro liên quan đến dự án. |
| Product risk | Rủi ro liên quan đến sản phẩm. |
| Risk analysis | Phân tích rủi ro. |
| Risk control | Kiểm soát rủi ro. |
| Configuration management | Quản lý cấu hình và phiên bản. |
| Defect management | Quản lý defect. |
| Defect report | Báo cáo defect. |
