# Từ vựng Chương 3 (Tiếng Việt)

| Thuật ngữ | Nghĩa |
|---|---|
| Static testing | Kiểm thử không thực thi phần mềm. |
| Dynamic testing | Kiểm thử thực thi phần mềm. |
| Review | Xem xét sản phẩm làm việc để tìm lỗi hoặc cải thiện. |
| Inspection | Review chính thức có vai trò và quy trình rõ ràng. |
| Walkthrough | Người viết giải thích sản phẩm làm việc cho người khác. |
| Technical review | Review tập trung vào tính đúng đắn kỹ thuật. |
| Informal review | Review ít cấu trúc. |
| Formal review | Review có cấu trúc rõ ràng. |
| Static analysis | Phân tích tự động mà không cần chạy chương trình. |
| Anomaly | Điều bất thường hoặc vấn đề phát hiện trong sản phẩm làm việc. |
