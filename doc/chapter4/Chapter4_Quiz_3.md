### Question 1
Boundary Value Analysis (BVA) is based on the principle that:

A. Defects cluster at the boundaries of input ranges  
B. The center of a range is where defects occur  
C. All values in a range are equally likely to reveal defects  
D. Boundary testing is not useful  

**Answer:** A  
**Explanation:**  
BVA recognizes that defects tend to occur at the edges or boundaries of input ranges rather than in the middle.

---

### Question 2
What is the purpose of State Transition Testing?

A. To test all possible states of a system  
B. To test transitions between states and verify that invalid transitions are rejected  
C. To eliminate the need for other testing techniques  
D. To only test the final state  

**Answer:** B  
**Explanation:**  
State Transition Testing verifies that a system responds correctly to events and transitions between valid states, and rejects invalid transitions.

---

### Question 3
Use Case Testing involves:

A. Only testing the happy path  
B. Writing code instead of test cases  
C. Testing the main scenarios and alternative flows defined in use cases  
D. Eliminating the need for unit testing  

**Answer:** C  
**Explanation:**  
Use Case Testing derives test cases from use cases, testing both main and alternative flows to ensure the system fulfills user requirements.

---

### Question 4
In Pairwise Testing (Combinatorial Testing):

A. All possible combinations of input values must be tested  
B. Only two values per input parameter are tested  
C. Strategically selected combinations of inputs are tested to reduce test cases while maintaining good coverage  
D. It is only used in automated testing  

**Answer:** C  
**Explanation:**  
Pairwise testing reduces the number of test cases by testing meaningful combinations of parameter values, balancing coverage with efficiency.

---

### Question 5
The relationship between test case design and test data selection is:

A. They are unrelated  
B. Test case design defines what to test; test data selection determines the specific values to use  
C. Test data must be selected before designing test cases  
D. They are the same activity  

**Answer:** B  
**Explanation:**  
Test case design determines the scenarios and conditions to test. Test data selection provides the actual values that will be used in executing those test cases.
