# Chapter 4 Quiz

### Question 1 Which technique divides input data into groups expected to be handled alike?
A. State transition testing
B. Equivalence partitioning
C. Branch testing
D. Error guessing

**Answer:** B
**Explanation:** Equivalence partitioning divides data into partitions and selects representative values from them.

---

### Question 2 Which values are the main focus of boundary value analysis?
A. Only random values in the middle of a range
B. Values at and around the edges of a partition
C. Only values from invalid partitions
D. Only code branches

**Answer:** B
**Explanation:** Boundary value analysis targets values at, just below, and just above important boundaries.

---

### Question 3 Which technique is most suitable for combinations of business conditions and actions?
A. Decision table testing
B. Statement testing
C. Exploratory testing
D. Checklist-based testing

**Answer:** A
**Explanation:** Decision tables make condition and action combinations explicit.

---

### Question 4 What does branch testing primarily measure?
A. Whether each user story has a title
B. Whether decision outcomes are executed
C. Whether every input partition has equal size
D. Whether testers work in pairs

**Answer:** B
**Explanation:** Branch testing exercises the possible outcomes of decisions in the internal structure.

---

### Question 5 What is a defining characteristic of ATDD?
A. Acceptance tests are written after release
B. Acceptance tests are written before implementation through team collaboration
C. Only developers can define acceptance criteria
D. Tests must avoid business examples

**Answer:** B
**Explanation:** ATDD uses collaborative examples and acceptance tests before implementation to create shared expectations.
