# ISTQB Chapter 4 Glossary

## Key terms
- Test technique: A method used to derive test cases.
- Black-box testing: Testing based on external behavior without looking at internal code.
- White-box testing: Testing based on internal structure, logic, or code.
- Equivalence partitioning: Grouping inputs into valid and invalid classes.
- Boundary value analysis: Testing values at the edges of valid ranges.
- Decision table testing: Testing combinations of conditions and actions.
- State transition testing: Testing behavior across different states.
- Statement coverage: The percentage of statements executed by tests.
- Branch coverage: The percentage of branches executed by tests.
- Error guessing: Using experience to anticipate likely defects.
- Exploratory testing: Learning and testing at the same time.
- Checklist-based testing: Using a checklist of items to guide testing.
- User story: A short description of a feature from the user perspective.
- Acceptance criteria: Conditions that must be met for a feature to be accepted.
- ATDD (Acceptance Test-Driven Development): Writing acceptance tests before implementing the feature.
