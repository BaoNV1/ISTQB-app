# Sơ đồ tư duy Chương 3 (Tiếng Việt)

## Chương 3: Kiểm thử tĩnh

```mermaid
mindmap
  root((Chương 3: Kiểm thử tĩnh))
    Cơ bản về Kiểm thử tĩnh
      Định nghĩa
        Xem xét sản phẩm mà không thực thi phần mềm
      Sản phẩm công việc
        Yêu cầu / User stories
        Thiết kế & Kiến trúc
        Mã nguồn
        Test case / Test plan
        Tài liệu, mô hình...
      Giá trị của Kiểm thử tĩnh
        Phát hiện lỗi sớm
        Giảm chi phí sửa lỗi
        Cải thiện chất lượng
        Tăng giao tiếp
      Static vs Dynamic
        Static: Không chạy code
        Dynamic: Phải chạy code
    Quy trình Phản hồi và Review
      Lợi ích phản hồi sớm
        Phát hiện hiểu nhầm sớm
        Cải thiện chất lượng
        Tăng sự tham gia stakeholder
      Các bước Review
        Lập kế hoạch
        Kick-off
        Chuẩn bị cá nhân
        Họp review
        Sửa lỗi & Báo cáo
        Follow-up
      Vai trò trong Review
        Author (Tác giả)
        Reviewer
        Moderator / Facilitator
        Scribe (Người ghi chép)
        Manager
      Các loại Review
        Informal Review
        Walkthrough
        Technical Review
        Inspection
      Yếu tố thành công
        Mục tiêu rõ ràng
        Người tham gia phù hợp
        Chuẩn bị đầy đủ
        Điều hành tốt
        Văn hóa không đổ lỗi
        Hỗ trợ của quản lý
```
