### Question 1
What does static testing examine?

A. Software execution behavior
B. Work products without execution
C. Performance under load
D. Security vulnerabilities

**Answer:** B
**Explanation:** Static testing inspects work products such as requirements, design, or code without running the software.

### Question 2
Which role records issues and decisions during a review?

A. Author
B. Reviewer
C. Moderator
D. Scribe

**Answer:** D
**Explanation:** The scribe documents findings, issues, and decisions during the review process.

### Question 3
Which activity is most formal and structured?

A. Informal review
B. Walkthrough
C. Technical review
D. Inspection

**Answer:** D
**Explanation:** Inspection is a formal review process with defined roles, rules, and documented outputs.

### Question 4
What is a key benefit of static testing?

A. It tests runtime performance.
B. It reduces early defect detection.
C. It lowers costs by finding defects early.
D. It replaces dynamic testing.

**Answer:** C
**Explanation:** Static testing helps lower costs by finding defects before they become more expensive to fix later.
