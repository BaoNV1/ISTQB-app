# ISTQB CTFL v4.0.1 – Chapter 3 Practice Quiz

### Question 1
What is the main characteristic of static testing?

A. It requires executing the software  
B. It examines work products without executing the software  
C. It only tests performance  
D. It can only be applied to source code  

**Answer:** B  
**Explanation:** Static testing reviews work products (requirements, design, code, etc.) without running the software.

---

### Question 2
Which of the following work products can be examined by static testing?

A. Only source code  
B. Only test cases  
C. Requirements, design documents, code, and test cases  
D. Only executable programs  

**Answer:** C  
**Explanation:** Almost any work product can be subject to static testing.

---

### Question 3
Which review type is the most formal?

A. Informal review  
B. Walkthrough  
C. Technical review  
D. Inspection  

**Answer:** D  
**Explanation:** Inspection is a formal review with defined roles, process, metrics, and documented results.

---

### Question 4
Who is typically responsible for recording issues and decisions during a review meeting?

A. Author  
B. Moderator  
C. Scribe  
D. Manager  

**Answer:** C  
**Explanation:** The scribe (recorder) documents findings, issues, and decisions.

---

### Question 5
What is a key benefit of static testing compared to dynamic testing?

A. It can find runtime performance issues more easily  
B. It can detect defects earlier and at lower cost  
C. It completely replaces the need for dynamic testing  
D. It only works after the code is fully written  

**Answer:** B  
**Explanation:** One of the main values of static testing is early defect detection, which significantly reduces the cost of fixing defects.

---

### Question 6
In a Walkthrough, who usually leads the meeting?

A. The Moderator  
B. The Manager  
C. The Author  
D. An independent reviewer  

**Answer:** C  
**Explanation:** In a walkthrough, the author presents and explains the work product to the participants.

---

### Question 7
Which of the following is a success factor for reviews?

A. Blaming the author for every defect found  
B. Having clear objectives and adequate preparation time  
C. Skipping individual preparation  
D. Only inviting people who are not familiar with the work product  

**Answer:** B  
**Explanation:** Clear objectives, proper preparation, good moderation, and a blame-free culture are important success factors.

---

### Question 8
What is the main difference between static testing and dynamic testing?

A. Static testing requires more tools  
B. Static testing does not execute the code, while dynamic testing does  
C. Dynamic testing can only be performed by developers  
D. Static testing is only useful for non-functional requirements  

**Answer:** B  
**Explanation:** The fundamental difference is that static testing does not involve executing the software, whereas dynamic testing does.

---

### Question 9
Which role is responsible for fixing the defects found during a review?

A. Reviewer  
B. Scribe  
C. Author  
D. Moderator  

**Answer:** C  
**Explanation:** The author of the work product is responsible for addressing and fixing the identified issues.

---

### Question 10
Early and frequent stakeholder feedback mainly helps to:

A. Increase the number of test cases  
B. Detect misunderstandings and improve product quality early  
C. Replace the need for system testing  
D. Reduce the number of developers needed  

**Answer:** B  
**Explanation:** Early feedback helps identify misunderstandings and improves quality before more expensive stages of development.

---

### Question 11
What is the main goal of a review?

A. To find defects in a work product
B. To execute the application
C. To replace all dynamic testing
D. To assign blame

**Answer:** A  
**Explanation:** Reviews examine work products to identify defects and improve quality before execution.

---

### Question 12
Which review role leads and manages the review process?

A. Author
B. Moderator
C. Scribe
D. Customer

**Answer:** B  
**Explanation:** The moderator plans and facilitates the review process.

---

### Question 13
What is individual preparation intended to achieve?

A. Allow reviewers to examine the work product before the meeting
B. Prevent reviewers from finding issues
C. Replace the review meeting in every case
D. Approve production deployment

**Answer:** A  
**Explanation:** Preparation helps reviewers understand the work product and identify potential issues efficiently.

---

### Question 14
Which review type is usually led by the author?

A. Inspection
B. Walkthrough
C. Audit
D. Formal technical review

**Answer:** B  
**Explanation:** In a walkthrough, the author commonly presents the work product and guides discussion.

---

### Question 15
What should reviewers focus on during a review?

A. Improving the work product
B. Criticizing the author personally
C. Avoiding all documentation
D. Proving that no future defect is possible

**Answer:** A  
**Explanation:** A constructive, product-focused review identifies issues without blaming individuals.

---

### Question 16
Which activity is an example of static analysis?

A. Executing a load test
B. Checking source code for unreachable code
C. Testing a login through a browser
D. Measuring response time under load

**Answer:** B  
**Explanation:** Static analysis examines code without executing it and can identify issues such as unreachable code.

---

### Question 17
Why can static testing be performed before executable software exists?

A. It examines work products without execution
B. It requires a production environment
C. It only tests runtime behavior
D. It depends on completed deployment

**Answer:** A  
**Explanation:** Requirements, designs, and other artifacts can be reviewed before software execution is possible.

---

### Question 18
What is a characteristic of an inspection?

A. It is a highly formal review with defined roles
B. It is always performed by one person
C. It requires no preparation
D. It only examines performance

**Answer:** A  
**Explanation:** Inspections use a defined process, roles, preparation, and recorded results.

---

### Question 19
What is a benefit of a shared review checklist?

A. It supports consistent review coverage
B. It guarantees zero defects
C. It eliminates the need for reviewers
D. It prevents requirements changes

**Answer:** A  
**Explanation:** Checklists remind reviewers of common issue categories and improve consistency.

---

### Question 20
Which culture best supports effective reviews?

A. A blame-oriented culture
B. A culture focused on learning and improvement
C. A culture that hides issues
D. A culture that skips preparation

**Answer:** B  
**Explanation:** Reviews work best when participants can raise issues openly and focus on improving the product.
