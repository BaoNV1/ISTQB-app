# Chapter 3 Additional Quiz – Static Testing

### Question 1
Which review type is the most formal?
A. Informal Review  
B. Walkthrough  
C. Technical Review  
D. Inspection  

**Answer:** D  

### Question 2
Who leads a Walkthrough?
A. Moderator  
B. Author  
C. Scribe  
D. Manager  

**Answer:** B  

### Question 3
What is a key benefit of static testing?
A. It finds runtime performance issues  
B. It detects defects early and reduces cost  
C. It replaces all dynamic testing  
D. It only works on executable code  

**Answer:** B  

### Question 4
Which role records issues during a review?
A. Author  
B. Reviewer  
C. Scribe  
D. Manager  

**Answer:** C  

### Question 5
Static testing can be applied to:
A. Only source code  
B. Requirements, design, code, test cases, documentation  
C. Only running systems  
D. Only user manuals  

**Answer:** B
