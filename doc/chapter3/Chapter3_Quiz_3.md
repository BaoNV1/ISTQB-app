# ISTQB CTFL v4.0.1 – Chapter 3 Additional Quiz 3
## Static Testing - Part 3

---

### Question 1
Which of the following is an advantage of static testing?

A. It finds all runtime defects  
B. It can detect defects early before dynamic testing, reducing costs  
C. It eliminates the need for dynamic testing  
D. It requires the software to be executable  

**Answer:** B  
**Explanation:**  
Static testing can find defects early in the development lifecycle (in code, requirements, designs) before execution, reducing the cost of defect fixing.

---

### Question 2
A "Walkthrough" differs from an "Inspection" in that:

A. Walkthroughs have mandatory elements; inspections do not  
B. Inspections are led by the author; walkthroughs are led by a moderator  
C. Walkthroughs are less formal and are often led by the author, while inspections are more formal and structured  
D. Walkthroughs find more defects than inspections  

**Answer:** C  
**Explanation:**  
Walkthroughs are less formal, often led by the author. Inspections are more formal with specific roles, checklists, and entry/exit criteria.

---

### Question 3
What is the primary goal of a Technical Review?

A. To ensure compliance with standards and procedures  
B. To find defects and improve the product  
C. To discuss the architecture of the entire system  
D. To train junior developers  

**Answer:** B  
**Explanation:**  
Technical reviews aim to find defects and improve product quality through peer evaluation of technical artifacts.

---

### Question 4
Which statement about static analysis tools is TRUE?

A. They require the code to be executed  
B. They can automatically detect certain types of defects like unreachable code and undefined variables  
C. They are only useful for dynamic testing  
D. They find all possible defects  

**Answer:** B  
**Explanation:**  
Static analysis tools analyze code without execution to detect defects, vulnerabilities, and style issues automatically.

---

### Question 5
What is the relationship between static testing and dynamic testing?

A. Static testing replaces dynamic testing  
B. Dynamic testing replaces static testing  
C. They are complementary; static testing finds defects early, dynamic testing finds runtime issues  
D. They cannot be used together  

**Answer:** C  
**Explanation:**  
Static and dynamic testing have different strengths. Static testing catches defects in artifacts early. Dynamic testing finds runtime failures and behavior issues.
