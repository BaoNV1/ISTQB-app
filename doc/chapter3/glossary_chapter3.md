# ISTQB Chapter 3 Glossary

## Key terms
- Static testing: Testing that does not execute the software.
- Dynamic testing: Testing that executes the software.
- Review: A process where work products are examined by one or more people.
- Inspection: A formal review with defined roles and procedures.
- Walkthrough: A review where the author explains the work product to others.
- Technical review: A review focused on technical correctness.
- Informal review: A less formal review with fewer structured steps.
- Formal review: A structured review with defined roles and outputs.
- Static analysis: Automated analysis of code or other work products.
- Anomaly: A deviation or issue found in a work product.
