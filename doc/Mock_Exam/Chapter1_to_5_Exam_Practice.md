# Chapter 1: Fundamentals of Testing

### Question 1
Which of the following is a typical test objective?
A. Fixing defects  
B. Finding defects  
C. Writing production code  
D. Managing the project budget  

**Answer:** B

### Question 2
What is the main difference between Testing and Debugging?
A. Testing finds defects; Debugging finds the root cause and fixes them  
B. They are the same activity  
C. Debugging is only performed by testers  
D. Testing is only static  

**Answer:** A

### Question 3
Which of the following is NOT one of the seven testing principles?
A. Testing shows the presence of defects, not their absence  
B. Exhaustive testing is impossible  
C. Testing can prove the software is correct  
D. Defects cluster together  

**Answer:** C

### Question 4
Error → ______ → Failure
A. Root cause  
B. Defect  
C. Test case  
D. Requirement  

**Answer:** B

### Question 5
What does the Whole Team Approach mean?
A. Only testers are responsible for quality  
B. Everyone shares responsibility for quality  
C. Developers never test  
D. Testers work completely independently  

**Answer:** B

### Question 6
Which activity is part of the Test Process?
A. Writing production code  
B. Test Design  
C. Marketing the product  
D. Hiring developers  

**Answer:** B

C. Only testing in production

Which test level is typically performed by developers?
A. Acceptance Testing  
B. System Testing  
C. Component (Unit) Testing

Confirmation Testing is also known as:
A. Regression Testing  
B. Retesting  
C. Exploratory Testing

Maintenance Testing is usually triggered by:
A. Only new projects  
B. Modifications, migration, or retirement

# Chapter 4: Test Analysis and Design

### Question 1
Which technique divides input data into groups that are expected to be handled the same way?
A. State transition testing  
B. Equivalence Partitioning  
C. Branch testing  
D. Error guessing  

**Answer:** B

### Question 2
A field accepts values from 1 to 100. How many equivalence partitions are there (including invalid)?
A. 2  
B. 3  
C. 4  
D. 5  

**Answer:** B  
**Explanation:** <1 (invalid), 1–100 (valid), >100 (invalid)

### Question 3
Which technique is best for combinations of business conditions?
A. Equivalence Partitioning  
B. Decision Table Testing  
C. Statement Testing  
D. Error Guessing  

**Answer:** B

### Question 4
100% Branch Coverage guarantees:
A. 100% Statement Coverage  
B. 100% Requirement Coverage  
C. All defects are found  
D. Nothing  

**Answer:** A

### Question 5
What is a defining characteristic of ATDD?
A. Acceptance tests are written after release  
B. Acceptance tests are written collaboratively before implementation  
C. Only developers define acceptance criteria  
D. Tests must avoid business examples  

**Answer:** B

### Question 6
In State Transition Testing, covering all valid transitions is:
A. Weaker than covering only states  
B. Stronger than covering only states  
C. The same as covering states  
D. Not useful  

**Answer:** B

### Question 7
Which technique relies mainly on the tester’s experience to predict defects?
A. Equivalence Partitioning  
B. Error Guessing

# Chapter 5: Managing the Test Activities

### Question 1

A. To list all defects found  
B. To describe objectives, approach, resources, and schedule of testing  
C. To replace test cases  
D. To only document exit criteria  

**Answer:** B

### Question 2
How is Risk Level calculated?
A. Likelihood + Impact  
B. Likelihood × Impact  
C. Impact – Likelihood  
D. Number of defects  

**Answer:** B

### Question 3
Which of the following is a Product Risk?

B. Test environment is delayed  
C. The system may crash under high load  
D. Project budget is reduced  

**Answer:** C

### Question 4

A. When testing can finish  
B. When testing can start  
C. Only defect counts  
D. Only test tools

C. Only manual tests  
D. Equal number of tests at every level

### Question 6
