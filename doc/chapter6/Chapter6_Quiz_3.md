# ISTQB CTFL v4.0.1 – Chapter 6 Additional Quiz 3
## Test Tools - Part 3

---

### Question 1
Categories of test tools include all of the following EXCEPT:

A. Test execution and reporting tools  
B. Performance and monitoring tools  
C. Requirement writing tools  
D. Management and DevOps tools  

**Answer:** C  
**Explanation:**  
Test tools support testing activities. Requirements writing is typically done with documentation tools, not dedicated test tools.

---

### Question 2
The success of test automation depends on:

A. Only choosing the best tool available  
B. Proper planning, realistic scope, team skills, and gradual implementation  
C. Having the most testers  
D. Full automation of all tests immediately  

**Answer:** B  
**Explanation:**  
Successful automation requires starting with achievable goals, investing in training, managing expectations, maintaining tests, and evolving with the project.

---

### Question 3
Why is a proof-of-concept (PoC) recommended before full test automation adoption?

A. To avoid making large initial investments in failed solutions  
B. To demonstrate tool capabilities, identify challenges, and validate the approach  
C. To delay all automation efforts  
D. Because PoCs guarantee success  

**Answer:** B  
**Explanation:**  
A PoC helps the team understand the tool's capabilities, identify integration challenges, estimate effort, and determine if the tool suits their needs.

---

### Question 4
Test coverage metrics in automated testing:

A. Are always 100% when automation is used  
B. Must still be monitored to ensure tests cover requirements and risks  
C. Are irrelevant in automated testing  
D. Only measure code lines executed  

**Answer:** B  
**Explanation:**  
Automation doesn't automatically improve coverage. Teams must deliberately design tests to cover requirements, risks, and business-critical paths.

---

### Question 5
The relationship between continuous integration (CI) and test automation is:

A. CI does not require test automation  
B. CI relies heavily on test automation for rapid feedback on code changes  
C. Test automation is only for CI environments  
D. They are unrelated concepts  

**Answer:** B  
**Explanation:**  
CI pipelines depend on test automation to quickly validate code changes, run tests automatically on each commit, and provide rapid feedback to developers.
