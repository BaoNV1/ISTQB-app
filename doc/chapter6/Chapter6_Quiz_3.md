# ISTQB CTFL v4.0.1 – Chapter 6 Practice Quiz 3
## Focus: Benefits & Risks of Test Automation (FL-6.2.1)

---

### Question 1
Which statement is TRUE?

A. Buying an automation tool always guarantees lasting benefits  
B. Each new tool requires effort to achieve real benefits (introduction, maintenance, training)  
C. Automation removes all project risks  
D. Manual testing is never needed after automation  

**Answer:** B  
**Explanation:** Simply acquiring a tool does not guarantee success; effort is needed for introduction, maintenance, and training.

---

### Question 2
Which is a syllabus **benefit** of test automation?

A. Vendor retires the product  
B. Prevention of simple human errors through consistency and repeatability  
C. Open-source project abandonment  
D. Tool fails regulatory standards  

**Answer:** B  
**Explanation:** Consistency and repeatability help prevent simple human errors (systematic data, consistent execution order/frequency).

---

### Question 3
Automation freeing testers to design new, deeper, more effective tests is a:

A. Risk  
B. Benefit  
C. Type of entry criterion only  
D. Definition of Done only  

**Answer:** B  
**Explanation:** Reduced repetitive work can give testers more time for better test design.

---

### Question 4
Which is a syllabus **risk**?

A. Faster time to market from shorter execution  
B. Inaccurate estimates of time, cost, and effort to introduce and maintain the tool  
C. Objective coverage measures  
D. Aggregated progress graphs for reporting  

**Answer:** B  
**Explanation:** Underestimating introduction, script maintenance, and process-change effort is a listed risk.

---

### Question 5
“Using automation when manual testing is more appropriate” is classified as:

A. A benefit  
B. A risk  
C. A mandatory practice  
D. A test completion activity  

**Answer:** B  
**Explanation:** The syllabus lists using a test tool when manual testing is more appropriate as a risk.

---

### Question 6
Ignoring the need for human critical thinking because the team trusts the tool completely is:

A. Recommended by FL-6.2.1  
B. Over-reliance on a tool (a risk)  
C. A type of product risk analysis  
D. Configuration management  

**Answer:** B  
**Explanation:** Relying on a tool too much and ignoring human critical thinking is a risk.

---

### Question 7
Which risk relates to the tool supplier?

A. More objective coverage measurement  
B. Vendor may go out of business, retire the tool, sell it, or provide poor support  
C. Faster regression execution  
D. Systematic creation of test data  

**Answer:** B  
**Explanation:** Dependency on the tool vendor is an explicit risk.

---

### Question 8
An open-source automation framework stops receiving updates. This illustrates:

A. A benefit of open source only  
B. A risk of abandoned open-source software  
C. Guaranteed regulatory compliance  
D. Automatic increase in branch coverage  

**Answer:** B  
**Explanation:** Open-source tools may be abandoned or require frequent component updates.

---

### Question 9
Choosing a tool that does not comply with safety or regulatory standards is:

A. Always acceptable for CTFL projects  
B. A risk listed in the syllabus  
C. A benefit of non-functional tools  
D. Required for CI/CD  

**Answer:** B  
**Explanation:** Selecting an unsuitable tool that fails regulatory/safety requirements is a risk.

---

### Question 10
Which pair is CORRECT?

A. Benefit — unrealistic expectations; Risk — faster feedback  
B. Benefit — reduced repetitive work; Risk — platform incompatibility  
C. Benefit — vendor bankruptcy; Risk — consistent regression runs  
D. Benefit — abandoned open-source; Risk — objective metrics  

**Answer:** B  
**Explanation:** Reduced repetitive work is a benefit; incompatibility with the development platform is a risk.

---

### Question 11
Easier access to failure rates and execution-duration graphs mainly supports:

A. Only coding standard reviews  
B. Test management and test reporting  
C. Removing monitoring entirely  
D. Avoiding all control directives  

**Answer:** B  
**Explanation:** A benefit is easier access to testing information for management and reporting.

---

### Question 12
Which statement best reflects the syllabus view of automation?

A. Automation always finds every defect  
B. Automation can save time and improve consistency, but brings risks that need analysis and mitigation  
C. Automation replaces the need for any test design skill  
D. Automation is only useful for exploratory testing  

**Answer:** B  
**Explanation:** Benefits exist, but success is not automatic; risks must be analyzed and mitigated.
