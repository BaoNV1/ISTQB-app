# Từ vựng ISTQB Chương 6 (Tiếng Việt)

Bảng này giúp bạn tra cứu nhanh từng thuật ngữ và nghĩa của nó.

| Thuật ngữ | Nghĩa |
|---|---|
| Test tool | Một công cụ phần mềm hoặc phần cứng hỗ trợ các hoạt động kiểm thử. |
| Test management tool | Công cụ dùng để lập kế hoạch, tổ chức, giám sát và báo cáo hoạt động kiểm thử. |
| Defect tracking tool | Công cụ dùng để ghi nhận, quản lý và theo dõi defect. |
| Static analysis tool | Công cụ kiểm tra mã hoặc tài liệu mà không cần thực thi phần mềm. |
| Automation tool | Công cụ giúp chạy test tự động. |
| Test automation | Sử dụng phần mềm để thực thi test tự động. |
| Repeatability | Thực hiện lại cùng một test theo cùng cách và nhận được kết quả nhất quán. |
| Regression coverage | Mức độ kiểm thử hồi quy được hỗ trợ bởi tự động hóa. |
| Benefits of automation | Thực thi nhanh hơn, nhất quán hơn và hỗ trợ tốt hơn cho regression testing. |
| Risks of automation | Chi phí bảo trì cao, script test lỗi thời và cảm giác tự tin sai khi test yếu. |
| Continuous testing | Kiểm thử liên tục trong quy trình phát hành nhanh. |

## Mẹo ghi nhớ nhanh

Công cụ giúp kiểm thử, nhưng kiểm thử tốt vẫn phụ thuộc vào con người giỏi, thiết kế tốt và phân tích tốt.
