# ISTQB Chapter 6 Glossary

## Key terms
- Test tool: A tool that supports testing activities.
- Test automation: Using software to run tests automatically.
- Test management tool: A tool used to plan, monitor, and report testing.
- Defect tracking tool: A tool used to record and manage defects.
- Static analysis tool: A tool that analyzes code or work products without executing them.
- Benefit of automation: Faster, repeatable, and more consistent execution of tests.
- Risk of automation: Maintenance effort, false confidence, and dependency on tools.
