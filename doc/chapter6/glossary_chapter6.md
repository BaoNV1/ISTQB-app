# ISTQB Chapter 6 Glossary

This table gives you a quick overview of the key terms in Chapter 6.

| Term | Meaning |
|---|---|
| Test tool | A software or hardware tool that supports testing activities. |
| Test management tool | A tool used to plan, organize, monitor, and report testing activities. |
| Defect tracking tool | A tool used to record, manage, and track defects. |
| Static analysis tool | A tool that checks code or documents without executing the software. |
| Automation tool | A tool that helps run tests automatically. |
| Test automation | Using software to execute tests automatically. |
| Repeatability | Running the same test in the same way and getting consistent results. |
| Regression coverage | The amount of regression testing supported by automation. |
| Benefits of automation | Faster execution, better consistency, and stronger regression support. |
| Risks of automation | High maintenance cost, outdated scripts, and false confidence if tests are weak. |
| Continuous testing | Testing continuously as part of fast delivery pipelines. |
| Tool support | Tools help testing, but they do not replace critical thinking or good judgment. |

## Quick memory tip

Tools help testing, but good testing still depends on good people, good design, and good analysis.
