# ISTQB Chapter 6 Glossary

This glossary explains the key ideas in Chapter 6 in a more practical and easy-to-understand way.

## 1. Test Tools
- Test tool: A software or hardware tool that supports testing activities.
- Why tools matter: They help make testing faster, more consistent, and easier to manage.

## 2. Tool Support for Testing
- Test management tool: A tool used to plan, organize, monitor, and report testing activities.
- Defect tracking tool: A tool used to record, manage, and track defects.
- Static analysis tool: A tool that checks code or documents without executing the software.
- Automation tool: A tool that helps run tests automatically.

## 3. Test Automation
- Test automation: Using software to execute tests automatically.
- Common benefits:
  - faster execution
  - repeatability
  - better consistency
  - support for regression testing
- Common challenges:
  - maintenance effort
  - initial setup cost
  - possible false confidence if tests are weak

## 4. Benefits and Risks of Test Automation
- Benefits of automation:
  - saves time on repetitive tests
  - improves regression coverage
  - supports continuous testing
- Risks of automation:
  - high maintenance cost
  - test scripts may become outdated
  - automation cannot replace human judgment
  - poor test design can still miss important defects

## 5. Important Reminder
- Tools support testing, but they do not replace critical thinking, test design, and good judgment.
- A good tester still needs to understand the system and the risks being tested.

## Quick memory tip
- Tools help testing, but good testing still depends on good people, good design, and good analysis.
