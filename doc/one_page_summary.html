ISTQB CTFL One-Page Summary

Chapter 1 – Fundamentals of Testing

  • Testing helps find defects and improve quality.
  • Early testing saves cost and time.
  • Verification checks requirements; validation checks user needs.

Chapter 2 – Testing Throughout SDLC

  • Testing happens at different levels: component, integration, system, acceptance.
  • Testing should fit the development approach, including Agile and DevOps.
  • Shift-left means testing earlier.

Chapter 3 – Static Testing

  • Static testing uses review and analysis before execution.
  • Reviews can be informal, walkthroughs, technical reviews, or inspections.

Chapter 4 – Test Analysis and Design

  • Use black-box, white-box, experience-based, and collaboration-based techniques.
  • Equivalence partitioning and boundary value analysis are common black-box methods.

Chapter 5 – Managing Test Activities

  • Planning, risk management, monitoring, and reporting are core activities.
  • High-risk areas deserve more attention.

Chapter 6 – Test Tools and Automation

  • Tools help, but good testing still requires human judgment.
  • Automation improves efficiency, but needs maintenance and good test design.
